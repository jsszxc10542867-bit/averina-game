## 2. 컨셉

**제목:** [미정]

**한 줄:** [미정]

**핵심 아이디어**
- 주인공은 아무것도 모르는 채로 이세계에서 깨어난다. 플레이어와 같은 눈높이로 하나씩 알아간다. **[확정]**
- 한 번의 플레이는 하나의 이야기로 흘러 하나의 엔딩에 도달한다. **[제안]**
- NPC는 **그 플레이 안에서** 주인공의 행동을 기억하고 반응한다. (도와준 사람은 신뢰하고, 배신당한 사람은 등을 돌린다) **[제안]**
- 다회차의 재미는 죽음이 아니라 **능력치 배분, 선택, 엔딩 분기**에서 나온다. **[제안]**

**세계관의 비밀**
- **[확정]** 주인공이 마왕이라는 반전은 쓰지 않는다.
- **[확정]** 주인공은 소환 이유를 모른다.
- **[제안]** 아래 "이야기 뼈대"는 (1) 우연히 끼어든 사람 + (2) 누군가 불렀다를 합친 방향이다.
- **[미정]** 소환자는 누구이고, 무엇(누구)을 되찾으려는가

### 이야기 뼈대 **[제안 — 소환자 정체 미정]**

**배경**
- 이 세계의 시간은 주인공이 오기 **이전에** 여러 번 반복되어 왔다. (과거의 사연일 뿐, 플레이어가 죽어서 반복하는 구조는 아님)
- 반복을 만든 사람은 **누군가를 되찾으려고 시간을 되감은 소환자**다.
- 세계 안의 사람은 반복을 깰 수 없어서, 소환자는 **바깥세계 사람**을 불렀다. 그게 주인공이다.
- 겉으로 알려진 이야기는 "마왕이 세계를 멸망시키고 있다"이다. 실제로는 반복의 부작용이거나 소환자가 남긴 흔적이 오해된 것이다.

**흐름 (3막 초안)**
1. **1막 · 눈을 뜸:** 혼자 낯선 곳에서 깨어난다. 아무도 모른다. 마왕 소문을 듣고, 살아남는 법과 이 세계의 규칙을 배운다.
2. **2막 · 어긋난 단서:** 동료를 영입하고, 오래된 기록과 이상한 단서를 모은다. "이 세계는 예전에도 같은 일을 겪었다"는 사실이 드러난다.
3. **3막 · 소환자:** 소환자와 마주한다. 잃은 것의 정체가 밝혀지고, 이야기를 어떻게 끝낼지 정하는 선택이 온다.

**진엔딩:** 동료와의 관계와 모은 단서로 소환자의 잃은 것을 마주하고, "왜 아직도 포기하지 않았습니까?"에 답한다. (선택지: 돌아가고 싶어서 / 구하고 싶어서 / 복수하고 싶어서 / 직접 입력)

## 3. 게임 루프 **[제안]**

```
캐릭터 만들기 (이름, 능력치 배분)
  → 이세계 탐험 (이벤트, 선택, 동료 영입)
  → 단서 수집과 관계 쌓기
  → 소환자와의 마지막 선택
  → 엔딩
```

- 한 번의 플레이가 한 번의 이야기다. 끝나면 엔딩이 기록되고, 다시 시작한다.
- 다시 할 이유: 다른 능력치 조합, 다른 선택, 다른 동료, 아직 못 본 엔딩.
- 진엔딩은 한 번의 플레이 안에서 관계와 단서 조건을 채우면 열린다. (여러 판의 기록이 필요할지는 [미정])

## 4. 플레이어

### 4-1. 이름
- 시작 화면에서 입력 (글자 수 제한, 특수문자 필터)
- 대사에 `{이름}` 자리표시자를 쓰고, 한국어 조사(이/가, 은/는, 을/를)는 자동 처리한다

### 4-2. 능력치 **[제안]**

시작 배분 대상 (포인트 바이, 총 10점 안팎, 각 1~5):

| 능력치 | 쓰임 |
|---|---|
| 체력 | 버티기, 전투, 위험 돌파 |
| 손재주 | 만들기, 고치기, 훔치기 |
| 통찰 | 단서 발견, 기록 해독, 거짓 간파 |
| 친화 | 설득, 동료 영입, 거래 |
| 의지 | 공포와 유혹 저항, 세계의 진실을 견디기 |

진행 중 변하는 상태:

| 상태 | 설명 |
|---|---|
| 체력(HP) | 0이 되면 어떻게 되는가는 [미정] (9절 참고) |
| 정신력 | 진실을 마주할수록 깎임 |
| 명성 / 죄악 | 행동 기록. NPC 반응과 엔딩에 반영 |
| 돈 | 거래용 |

> 수정 메모: 능력치 개수 / 이름 / 총 포인트를 정해 주세요.
> 참고안의 검술·마법·거짓말·협박·도둑질 등은 "직업(클래스)" 아이디어로 돌릴 수도 있습니다.

## 5. 시스템

| 시스템 | 이번 안 | 비고 |
|---|---|---|
| 자유 행동 입력 | **[미정]** | 실시간 AI 필요 → 비용, API 키 보안, 콘텐츠 심사 문제. 1차 버전에서는 제외 권장 |
| NPC 기억 | **[제안]** 포함 | 한 번의 플레이 안에서 플래그로 구현 (예: `betrayed_mira = true`) |
| 선택 기록 | **[제안]** 포함 | 엔딩 분기와 진엔딩 조건에 사용 |
| 관계도 | **[제안]** 포함 | NPC별 호감/공포 수치 |
| 명성/악명 | **[제안]** 포함 | 명성, 죄악 두 축 |
| 세계 변화(죽을 때마다) | **[삭제]** | 사용 안 함 |
| 멀티 엔딩 | **[확정]** 포함 | 아래 6절 |
| 저장 | **[제안]** 자동 저장 | 모바일에서 중간에 끊겨도 이어 하기 |

**직접 입력은 진엔딩의 마지막 질문에만 쓰는 방식을 제안합니다.** 입력 내용은 AI 해석 없이 엔딩 문장에 그대로 인용합니다. 비용과 보안 위험이 없고 참고안의 핵심 효과는 살릴 수 있습니다.
